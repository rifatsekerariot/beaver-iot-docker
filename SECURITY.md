# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

**Do not report security issues via public issues.**

- Use [GitHub Security Advisories](https://github.com/rifatsekerariot/beaver-iot-docker/security/advisories/new), or
- Open a **private** security advisory.

We will acknowledge and address reports. Thank you.
